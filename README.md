# 因式分解闖關王・思考版

國中數學十字交乘因式分解闖關遊戲。這是對照版本：數字由學生自己拆、自己算，程式只驗證並用提問引導。原版請見 [factor-cross-quest](https://ryansu2021.github.io/factor-cross-quest/)。

線上網址：https://ryansu2021.github.io/factor-cross-quest-thinking/

## 與原版的差異

| 項目 | 原版 | 思考版 |
|---|---|---|
| 輸入 | 點選或拖曳程式篩好的因數 | 數字鍵盤自由輸入，正負自己決定 |
| 交叉相乘 | 按驗算後由程式算出 | 學生自己算，答對才進下一步 |
| 畫面 | 四格與結果同一畫面 | 拆數字 → 交叉相乘 → 相加 → 寫括號，逐步出現 |
| 回饋 | 指出錯在哪裡 | 提問引導，不直接給修改方式 |
| 愛心與魔王關時間 | 3 顆、5 分鐘 | 5 顆、8 分鐘 |

資料與原版分開存放。教師看板：在網址後加 `?teacher=1`，需輸入教師密碼。
